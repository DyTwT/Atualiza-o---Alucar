# AluCar 🚗

Landing Page da **AluCar**, desenvolvida como atualização do projeto utilizando **HTML5, CSS3 e Bootstrap 5**.

## 📌 Sobre o projeto

O projeto apresenta uma página responsiva para a AluCar, com informações sobre a empresa, opções de carros, seção de perguntas frequentes e formulário de contato.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap 5.3.8
* JavaScript

## ✨ Atualizações realizadas

* Navbar responsiva com menu hambúrguer;
* Carousel com imagens, indicadores, legendas e controles;
* Cards de veículos utilizando o sistema de Grid do Bootstrap;
* Seção FAQ com Accordion;
* Formulário de contato estilizado com Bootstrap;
* Modal de confirmação após o envio do formulário;
* Melhorias no design e na organização visual;
* Responsividade para dispositivos móveis.

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Para visualizar melhor a responsividade, teste também em diferentes tamanhos de tela.
